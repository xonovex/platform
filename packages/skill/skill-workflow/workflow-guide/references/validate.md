# Validate

1. Resolve the exact subject, optional subject revision, binding criteria, advisory
   perspectives, requested method, and applicable capabilities.
2. Block when no binding criterion can be resolved.
3. Start independent context when requested or when separation from implementation is
   a binding criterion; block when required isolation is unavailable.
4. Evaluate each binding criterion independently against reproducible evidence.
5. Return `pass`, `fail`, or `blocked` for every binding criterion.
6. Report advisory checks separately from the binding outcome and preserve each
   evidence entry's source, subject revision, freshness, and limitation.

Do not revise, accept, publish, or mutate the subject.
