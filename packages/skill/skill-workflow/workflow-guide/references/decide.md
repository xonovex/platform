# Decide

1. Resolve the decision question, explicit options, evidence, criteria, and applicable
   capabilities.
2. Compare every option against the same criteria.
3. Record one outcome with rationale, dissent, tradeoffs, and unresolved uncertainty.
4. Return the decision inline.

The decision is descriptive unless separate authority explicitly grants an effect. Do
not approve, reject, merge, publish, or change a protected gate.
