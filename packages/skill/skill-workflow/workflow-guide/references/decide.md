# Decide

1. Resolve the decision question, optional subject revision, supplied context,
   explicit options, evidence entries, criteria, and applicable capabilities.
2. Compare every option against the same criteria.
3. Reject stale, mismatched, or unattributed evidence when the criteria require
   revision-pinned support.
4. Record one outcome with rationale, rejected alternatives, dissent, tradeoffs, and
   unresolved uncertainty.
5. When the choice matters to later work, return a canonical context entry containing
   its stable ID, version, digest, supersedes relationship, type, summary, source,
   applicability, rationale, alternatives or tradeoffs, status, audience, and
   visibility.
6. Return the decision inline with the evidence entries it relied on.

The decision is descriptive unless separate authority explicitly grants an effect. Do
not approve, reject, merge, publish, comment, or change a protected gate.
