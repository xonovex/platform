# Decide

1. Resolve the decision question, optional subject revision, explicit options,
   evidence entries, criteria, and applicable capabilities.
2. Compare every option against the same criteria.
3. Reject stale, mismatched, or unattributed evidence when the criteria require
   revision-pinned support.
4. Record one outcome with rationale, dissent, tradeoffs, and unresolved uncertainty.
5. Return the decision inline with the evidence entries it relied on.

The decision is descriptive unless separate authority explicitly grants an effect. Do
not approve, reject, merge, publish, or change a protected gate.
