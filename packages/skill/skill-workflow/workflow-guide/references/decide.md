# Decide

1. Resolve the decision question, its options, the optional subject revision, supplied
   context, and applicable capabilities.
2. Compare every option on the same terms.
3. Reject stale or unattributed support when the question needs revision-pinned
   evidence.
4. Record one outcome with its reason, the rejected alternatives, any dissent, and the
   uncertainty that remains.
5. When the choice matters to later work, return it as a decision with what, why, and
   a code anchor, in the shape [handoffs.md](handoffs.md) defines.
6. Return the decision inline with the evidence it relied on.

A decision is descriptive: it does not approve, reject, merge, publish, comment, or
change a protected gate. See [governance.md](governance.md).
