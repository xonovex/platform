# review-run: Review an Exact Deliverable

## Core workflow

1. Resolve the Deliverable Publication native reference and immutable revision, intended target, source Development revisions, and selected review criteria.
2. Resolve reviewer identity, independence, qualification, allowed tools/data, and required external evidence from the workflow contract.
3. Compose deterministic analysis, static tools, CI/scanners, a bounded model, an independent bounded agent, or human review according to [assurance-contracts.md](assurance-contracts.md). For code diffs, load **code-review-guide** for findings shape, anchoring, labels, and reviewer-facing structure.
4. Verify each finding against the exact subject and authoritative sources.
5. Publish a Review result with exact subject revision, reviewer/evaluator origins and independence, findings, severity, disposition, evidence references, limitations, and unresolved items.

Review posts no Acceptance and performs no Integration. A bounded model or agent may draft findings, but it cannot claim human review, qualification, or merge authority.
