# Execute

## Goal

Carry out one bounded subject, preserve explicit scope, and report the observable result without implicit publication or workspace management.

## Procedure

1. Bound the work and resolve its exact subject, criteria, and explicit selections.
2. Load only explicitly selected or unambiguous domain, method, execution, and provider capabilities.
3. Let the selected provider interpret opaque references and revisions.
4. Execute the bounded work, verify criteria in proportion to risk, and preserve usable partial results when later actions fail.
5. Return changes, evidence, failures, and remaining work inline. Persist only to an explicit destination.

Execution never creates, merges, abandons, or cleans a workspace and never publishes implicitly. Trigger, executor, identity, and maturity do not select behavior.

## Error handling

- Stop when the subject is unbounded or selected-method criteria are missing.
- Report ambiguous providers and unavailable explicit capabilities without fallback.
- Preserve completed work and state the exact retry boundary after partial failure.
