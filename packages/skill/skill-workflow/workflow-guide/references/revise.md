# Revise

1. Resolve the exact source, optional subject revision, supplied context, explicit
   feedback, retained constraints, and applicable capabilities.
2. Produce a distinct successor that accounts for every feedback item.
3. Verify retained constraints and report any feedback that remains unresolved.
4. Return the successor inline with a concise change account and canonical records for
   still-applicable, superseded, invalidated, or newly established context.

Preserve the source. Do not overwrite or publish the successor.
