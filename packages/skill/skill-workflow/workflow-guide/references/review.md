# Review

1. Resolve the exact subject, optional subject revision, requested perspectives,
   criteria, and applicable capabilities.
2. Start independent context when requested or when the selected review method
   requires it; block and name the missing capability when isolation is mandatory but
   unavailable.
3. Inspect the subject without changing it.
4. Link each material finding to evidence and identify uncertainty.
5. Return the findings inline, distinguishing blocking from advisory concerns when the
   criteria support that distinction.

Use separate Review invocations against the same exact subject revision when
perspectives must be organizationally independent. Aggregate their returned evidence
as separate entries instead of blending reviewer identities or findings.

Do not revise the subject, persist the review, or grant approval.
