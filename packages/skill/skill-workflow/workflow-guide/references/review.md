# Review

1. Resolve the exact subject, optional subject revision, supplied context, requested
   perspectives, criteria, and applicable capabilities.
2. When independence is requested or required, pin the subject and inspect it without
   creator context or prior findings. Preserve those first-pass findings before
   resolving supplied context; block when mandatory isolation is unavailable.
3. Resolve context in a second pass, use it to understand intent and tradeoffs, and
   report which initial findings it confirmed or changed and which findings it added.
   Without independence, resolve context before the single review pass.
4. Link each material finding to evidence and identify uncertainty. Never promote
   explanatory context into validation evidence.
5. Return the findings inline, distinguishing blocking from advisory concerns when the
   criteria support that distinction.

Use separate Review invocations against the same exact subject revision when
perspectives must be organizationally independent. Aggregate their returned evidence
as separate entries instead of blending reviewer identities or findings.

Do not revise the subject, persist the review, or grant approval.
