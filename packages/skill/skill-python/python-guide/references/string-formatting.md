# string-formatting: Modern String Formatting

Use f-strings for interpolation, not `%` or `.format()`. Embed expressions inline and apply format specifiers after `:` (`{pi:.2f}`). Triple-quoted f-strings for multiline structured text.

```python
message = f"Hello, {name}! You are {age} years old."
formatted = f"Pi is approximately {pi:.2f}"
```
