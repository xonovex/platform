# solution-design-create: Create a Solution Design Result

Apply [early-lifecycle-contracts.md](early-lifecycle-contracts.md). Solution Design is optional unless the selected profile includes it.

## Core workflow

1. Resolve the exact Discovery, Research, Formulation, Experience Design, and Decision input revisions.
2. Select installed domain, architecture, security, privacy, data, platform, and technology capabilities independently.
3. Describe boundaries, interfaces, dependencies, data and control flows, qualities, constraints, failure behavior, operational concerns, trade-offs, alternatives, and unresolved risks.
4. Record applicable data-access, privacy, security, architecture, and regulated constraints before analysis.
5. Distinguish evidence, assumptions, design choices, and authoritative decisions; do not turn architecture advice into approval.
6. Publish a proposed Solution Design result with provider-native reference/revision and explicit critique, revise, and accept capabilities.
