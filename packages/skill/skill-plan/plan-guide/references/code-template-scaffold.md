# code-template-scaffold: Analyze Package Scaffolding Options

Survey available templates before scaffolding and recommend the best fit. Read-only: produces a research report.

## Technique

- Discover templates in `templates/`, `.templates/`, or `_templates/`
- Per template, document features, config options / substitution placeholders, dependencies, build system, deployment, and best-fit use cases
- Recommend by matching requirements to template fit
