# experience-design-create: Create an Experience Design Result

Apply [early-lifecycle-contracts.md](early-lifecycle-contracts.md). Experience Design is optional unless the selected profile includes it.

## Core workflow

1. Resolve the exact Discovery, Research, Formulation, and Decision input revisions.
2. Select installed user-research, interaction-design, prototyping, content, and accessibility capabilities independently; absence of one method does not disable the result kind.
3. Describe users and tasks, contexts of use, journeys or interactions, content and state behavior, accessibility decisions, representations or prototypes, assumptions, and unresolved questions.
4. Request applicable `data-access`, `privacy`, `accessibility`, and `regulated-applicability` intents before handling people or user data.
5. Record validation evidence separately from design choices and state its participants, method, scope, limitations, and confidence.
6. Publish a proposed Experience Design result with provider-native reference/revision and explicit critique, revise, and accept capabilities.
