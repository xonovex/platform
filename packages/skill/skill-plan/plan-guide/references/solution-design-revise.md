# solution-design-revise: Revise a Solution Design

1. Resolve the exact subject revision and every feedback, critique, research, and decision reference.
2. Enumerate each item and resolve, defer with rationale/owner, or reject with authority.
3. Propagate changes through boundaries, interfaces, flows, qualities, constraints, failure behavior, risks, and validation.
4. Re-evaluate affected evidence and decisions; mark stale references instead of silently carrying them forward.
5. Publish a new proposed Solution Design native revision with supersession and source relationships.

Apply [early-lifecycle-contracts.md](early-lifecycle-contracts.md); the original revision remains addressable.
