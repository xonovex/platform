# Conduct and Analyse

## Conduct

1. Confirm consent, recording choices, accessibility needs, and the participant's
   right to pause or withdraw.
2. Establish context without teaching the expected answer.
3. Ask open neutral questions and use silence or non-leading probes.
4. For tasks, present the goal and realistic starting state without naming controls or
   the intended path.
5. Capture time-stamped observations: behavior, task state, quote, context, and
   facilitator intervention.
6. Debrief after every session and update emerging questions without changing the core
   tasks so much that sessions cease to be comparable.

## Analyse

1. Extract observations before themes.
2. Group related observations while preserving participant and session traceability.
3. Distinguish a repeated pattern, an important single case, a contradiction, and an
   interpretation.
4. Write each finding as affected users plus context, observed problem or need,
   consequence, supporting observations, confidence, and limitation.
5. Search deliberately for disconfirming evidence and plausible researcher influence.
6. Separate evidence from recommendations; several interventions may address one
   finding.

Never publish raw participant identities, recordings, or sensitive quotes merely to
make findings feel more persuasive.
