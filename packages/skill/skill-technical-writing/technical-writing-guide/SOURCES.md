# Sources

## Repository technical-writing conventions

- **Provenance:** Repository-original guidance for outcome-first technical explanations, reports, documentation, status updates, and operational handoffs
- **Last reviewed:** 2026-08-29
- **Used for:** `SKILL.md`, `references/outcome-first.md`, `references/technical-precision.md`
- **References:** all
- **Aspects extracted:** Lead with the main message, decision, action, answer, or status; add evidence in descending importance; keep decisive caveats near the lead; preserve exact technical identifiers, conditions, comparisons, and constraints; do not display a BLUF label or invent missing facts.

## Refresh Workflow

1. Review corrections and evaluations involving technical prose order, uncertainty, caveat placement, terminology, and evidence.
2. Update the smallest owning reference.
3. Re-run trigger, routing, and output evaluations.
4. Update the review date after the guidance and evaluations agree.
