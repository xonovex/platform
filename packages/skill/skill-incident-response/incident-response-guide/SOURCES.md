# Sources

## Incident response recommendations

- **URL:** https://csrc.nist.gov/pubs/sp/800/61/r3/final
- **Last reviewed:** 2026-07-24
- **References:** `SKILL.md`, `references/declare-and-coordinate.md`, `references/mitigate-and-recover.md`, `references/communication-and-learning.md`
- **Aspects extracted:** Integrate preparation, detection, response, recovery, and
  improvement into risk management; use common response language; preserve evidence;
  communicate and learn across the incident lifecycle.

## Incident-management roles and practices

- **URL:** https://sre.google/workbook/incident-response/
- **Last reviewed:** 2026-07-24
- **References:** `SKILL.md`, `references/declare-and-coordinate.md`, `references/communication-and-learning.md`
- **Aspects extracted:** Declare early, mitigate first, and separate incident command,
  operations, and communications so coordination and stakeholder updates do not
  distract system mitigation.

## Managing incidents

- **URL:** https://sre.google/sre-book/managing-incidents/
- **Last reviewed:** 2026-07-24
- **References:** `references/declare-and-coordinate.md`, `references/mitigate-and-recover.md`
- **Aspects extracted:** Keep high-level command, operational changes, communication,
  and longer-horizon planning explicit; centralize the response record and control
  system mutation during an incident.
