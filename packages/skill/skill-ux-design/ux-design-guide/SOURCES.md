# Sources

## Human-centred design lifecycle

- **URL:** https://www.iso.org/standard/77520.html
- **Last reviewed:** 2026-07-24
- **References:** `SKILL.md`, `references/frame-and-model.md`,
  `references/handoff-and-change.md`
- **Aspects extracted:** Apply human-centred principles and activities throughout the
  lifecycle, base design on users and context, evaluate designs, and involve multiple
  disciplines.

## Human-centred design processes

- **URL:** https://www.iso.org/standard/63462.html
- **Last reviewed:** 2026-07-24
- **References:** `references/frame-and-model.md`,
  `references/handoff-and-change.md`
- **Aspects extracted:** Treat human-centred design as an explicit organizational
  process with outcomes and work products rather than a single design artifact.

## Prototyping

- **URL:** https://www.gov.uk/service-manual/design/making-prototypes
- **Last reviewed:** 2026-07-24
- **References:** `SKILL.md`, `references/prototype-and-evaluate.md`
- **Aspects extracted:** Explore and test alternatives before committing to a build,
  match prototype type to the question, continue prototyping across lifecycle stages,
  and do not treat prototype code as production-ready code.
