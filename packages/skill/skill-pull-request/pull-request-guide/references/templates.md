# templates: Use a Lean PR Template

Add a `PULL_REQUEST_TEMPLATE.md` (host-specific location) of 4-6 prompts, not a long mandatory-checkbox form that gets rubber-stamped. Match each section's depth to the PR size, and in a coordinated change set link sibling PRs to each other and to the shared work item.

```markdown
## What

## Why

## Changes

## Testing

## Tradeoffs / risks

## Related PRs
```
