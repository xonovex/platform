# Integrations Plugin

Use GitHub and GitLab for issues, pull requests, delivery, and continuous integration.

Install `xonovex-integrations@xonovex-marketplace` in Claude Code or Codex.

## Skills

- [github-guide](skills/github-guide/SKILL.md)
- [gitlab-guide](skills/gitlab-guide/SKILL.md)

## Validation

Run `npx moon run plugin-integrations:ci-check` from the repository root.
