# Languages Plugin

Write Python, shell, SQL, and Lua, including TypeScript compiled to Lua.

Install `xonovex-languages@xonovex-marketplace` in Claude Code or Codex.

- [lua-opinionated-guide](skills/lua-opinionated-guide/SKILL.md)

- [sql-postgresql-guide](skills/sql-postgresql-guide/SKILL.md)
- [typescript-to-lua-guide](skills/typescript-to-lua-guide/SKILL.md)

## Validation

Run `npx moon run plugin-languages:ci-check` from the repository root.
