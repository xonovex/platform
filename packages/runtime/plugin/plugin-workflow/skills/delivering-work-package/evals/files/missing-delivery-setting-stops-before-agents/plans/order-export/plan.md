# Objective

A shop owner exports the orders of a chosen period and downloads the file.

# Scope

In scope:

- An export model, an export API, an audit record and a download link

Out of scope:

- Scheduled exports

# Success criteria

- A shop owner can export the orders of any period of up to one year.
- Every export leaves an audit record.
