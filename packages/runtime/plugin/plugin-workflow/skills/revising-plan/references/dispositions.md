# Dispositions

## The four dispositions

| Disposition | Meaning |
| --- | --- |
| Applied | The item changed the bundle exactly as it asked. |
| Partly applied | Part of it changed the bundle; the row says which part and why the rest did not. |
| Not applied | Nothing changed, for a stated reason: the evidence does not support it, it belongs to another owner, or the answer changes nothing in the bundle. |
| Sent to settling-questions | The item is a new or still open question. This skill records where it goes and decides nothing. |

Use the whole set. An answered or reworded note is not "applied" unless the plan or a work file changed.

## Choosing one

1. Does the item give the operator's confirmed answer to an open, paused or partly settled decision? Apply it as a new settled decision file.
2. Does the evidence of the item remove the basis of a settled decision? Apply the reopening as a new open decision file, and send the question on. The row is partly applied: the reopening is applied, the answer is sent to **settling-questions**.
3. Is it a new question, or a question that stays open? Send it to **settling-questions**.
4. Does it change wording, scope, a criterion or a work file without deciding anything? Apply it, or apply the part the evidence supports.
5. Does the evidence contradict it, or does another owner own the target? Not applied, with that reason.

When an item mixes a settled part and an open part, split it: apply the settled part, send the open part on, and mark the row partly applied.

## Notes that are questions

Answer a question note from the code or the design record, and put the answer in the reply and in the rationale. Add to the plan only what changes a decision, a scope line or a success criterion. When the answer needs facts nobody has read, the item goes to **researching-change** or to **settling-questions**. Do not guess.

## Conflicts and gaps

- Two items that cannot both hold, and no evidence that picks one: send the conflict to **settling-questions** and apply neither.
- An item that names a decision file that does not exist: report the gap and stop for that item. Never write a stand-in.
- An instruction that would implement the plan (change code, open a ticket): not applied, because this skill revises documents only.

## The rationale

One sentence that names the file or the evidence behind the disposition, for example "the code applies the cap before discounts, so success criterion 2 now says so". A rationale that restates the disposition ("applied as asked") is not one.

## The table

Rows follow the order of the enumeration. The item cell holds the source and the quoted text of the note, so the source survives its removal from the file.
