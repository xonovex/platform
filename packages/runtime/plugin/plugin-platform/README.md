# Platform Plugin

Configure Moon tasks and build and operate Docker images, Kubernetes workloads, and Terraform infrastructure.

Install `xonovex-platform@xonovex-marketplace` in Claude Code or Codex.

## Skills

- [docker-guide](skills/docker-guide/SKILL.md)
- [kubernetes-guide](skills/kubernetes-guide/SKILL.md)
- [moon-guide](skills/moon-guide/SKILL.md)
- [terraform-guide](skills/terraform-guide/SKILL.md)

## Validation

Run `npx moon run plugin-platform:ci-check` from the repository root.
