# Agent Command Line Interface

- Move the agent release line in lockstep: `agent-cli-go`'s version and five `optionalDependencies`, all five `agent-cli-go-<platform>` packages, and `agent-cli-go-github` platform refs, with the matching `## <version>` `CHANGELOG.md` section from conventional commits, or `github-publish` fails or ships stale notes. One invocation moves the whole line, never a loop over `<project>:version-bump`: `npx moon run workspace-config:version-bump-lockstep -- --lockstep agent-cli-go,agent-cli-go-darwin-arm64,agent-cli-go-darwin-x64,agent-cli-go-linux-arm64,agent-cli-go-linux-x64,agent-cli-go-win32-x64 --type minor`, which writes every version and every exact `@xonovex/*` reference as one transaction and generates each `CHANGELOG.md` section; preview with `--dry-run` first.
- Resolve isolators and provisioners through the `internal/sandbox` interfaces, explicit `Registry`, and method-agnostic `sandbox.EnforcePolicy`; only `internal/sandbox/plugins.DefaultRegistry()` imports concrete plugins. Add a plugin as a package plus one `Register` call, and build isolated registries in tests.
- Give every `RunConfig` in an isolation test a `t.TempDir()` `HomeDir`, which the package's own config helper does: `isoshared.ResolveHomeDir("")` falls back to the host home, so an empty `HomeDir` binds whatever agent configuration the developer happens to have and moves coverage between a workstation and CI. `forbidigo` fails a test that reads the host home directly.
